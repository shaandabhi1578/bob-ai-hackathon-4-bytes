# Submission Instructions & Contributing Guidelines

This repository represents the official entry for **GridGuard AI** submitted to the **IBM Bob AI Hackathon**.

## Structure Rules (Do Not Delete)
- `submission.yaml` must exist at the root with all metadata filled.
- `docs/setup-guide.md` must provide end-to-end reproducible setup commands.
- `demo/demo-video-link.txt` must contain a working video demonstration URL.
- `demo/screenshots/` must contain at least 3 screenshots of the running system.
- `bob_sessions/` must contain IBM Bob session export reports and token consumption summaries.
- Real API credentials must never be committed to `.env` or repository files.
